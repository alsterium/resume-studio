# 書類別TeX bundle

正式Projectは検証後、履歴書／職務経歴書の書類モデルに変換し、選択された同梱テンプレートで`GeneratedBundle`を生成する。入力テキストは共通エスケープ、本文は限定AST visitorを通す。入力をTeX命令として評価したり、テンプレートへの文字列置換を行ったりしない。

## 出力契約

- `main.tex`：固定の入口。LuaLaTeX、ltjsarticle、luatexja-preset（Harano Aji）で`content.tex`を読み込む。
- `content.tex`：書類の項目を固定マクロへ渡す。履歴書は基本情報・2連絡先・学歴／職歴／資格の行・志望動機・希望欄、職務経歴書は氏名・日付・要約・スキル／共通資格・会社／案件の全項目・自己PRを出力する。配列順を保持する。
- `resume.sty`または`career.sty`：紙面・項目の組版定義。履歴書はT18の罫線帳票。職務経歴書はT19の見出し・灰色帯・2列スキル表。最大長などの境界検証はT20で行う。
- `manifest.json`：テンプレートID・版・表示名・書類種別・対応Schema・エンジン・必要パッケージ／フォント。
- 履歴書だけ、選択写真を正規化して`photo-1.png`または`photo-1.jpg`へ展開する。未選択写真や元画像パス、Projectの管理用ID／titleは紙面へ出さない。

同梱版は`resume-standard`／`career-standard`の`1.0.0`、Schema 1、LuaLaTeX。ID・版・書類種別・Schemaの完全一致で解決し、非対応なら`TEMPLATE_NOT_FOUND`として拒否する。JSONの指定版を自動変更しない。画面の「テンプレート一覧を確認」から利用可能な版を明示選択すると未保存変更になる。

履歴書の年齢は書類日付時点で計算。未入力の年月・任意欄は空欄。職務経歴の終了年月nullは在籍中／進行中、空文字は空欄を保持する。空の任意会社項目・案件本文／URL・自己PRは見出しごと省略する。URLはHTTP(S)として検証してリンク先を正規化・エスケープし、表示の各文字間に折返し候補を入れる。リンク先には折返し命令を入れない。

## 履歴書の帳票と続紙

A4・余白18mm、本文10.5ptのゴシック体、ページ番号なし。1ページ目には書類日付、氏名・ふりがな・生年月日・満年齢・任意性別、右上の30×40mm写真枠、住所／電話・メールの2列を配置する。写真は縦横比を保持する。別連絡先と未選択の写真枠は空欄でも残す。

学歴と職歴は一つの年／月／内容表にまとめ、区分行と右寄せの「以上」を付ける。列幅は12%／8%／80%、外枠0.6pt、行罫線0.25pt。年・月の間とふりがなの下は点線とする。2ページ目は学歴・職歴の続き、免許・資格、志望動機、本人希望欄の順に配置する。

`ResumeFinish`が各欄の測定済み行を消費して通常の2ページを組む。履歴行・本文を巨大な一体の表セルにせず、TeXの行単位で分割できる縦リストに保持する。複数行の履歴の途中でも分割でき、年月はその行の先頭に表示する。空き領域は空行を補う。

初期設定は行高7.5mm、1ページ目の履歴120mm、2ページ目の履歴45mm・資格45mm、志望動機75mm・希望50mm。見出し高は別に加算する。長い連絡先によって1ページ目の残り高さが減った場合、履歴領域を縮める。寸法の変更は`resume.sty`の設定マクロで行い、JSONに組版用の値を持たせない。

通常欄に収まらなかった内容は、基本の2ページの後へ学歴・職歴→免許・資格→志望動機→本人希望の順に続紙を追加する。切り捨てない。PDF.jsで読み取った実ページ数が2を超える履歴書にだけ、プレビューで続紙の確認を促す。下書き・職務経歴書にはこの警告を出さない。

空・通常（写真あり）・長い住所／学校名／多数の履歴と資格／長文の実PDFで、2ページの維持、続紙の順序、末尾文字、A4寸法、欠字・はみ出し警告なしを検証する。全フィールドの最大長、巨大な基本情報、写真形式の網羅はT20で追加検証する。

入力はProject JSONの制限に従い、生成後の`content.tex`は64MiB以内（超過はエラー、切り捨てなし）。bundleの書込は呼出側が所有する新規作業ディレクトリで行う。資源名は固定の許可リストに限定し、重複・既存ファイル／symlinkは書込前に拒否、各ファイルはcreate_newで作成する。途中のI/Oエラーでは作業ディレクトリ所有者が片付ける。コンパイル時はTempDirが成功／失敗双方を片付ける。利用者向け保存・上書き確認はT23で実装する。

## 職務経歴書の流し込み

A4・余白18mm、本文10.5pt／行送り17ptのゴシック体、ページ番号なし。18ptの書類タイトルに二重線を添え、日付・氏名を右寄せする。セクションは14pt太字と全幅の下線、会社名・期間は薄い灰色の帯、案件は白抜き菱形と太字の名称、期間は小さな灰色文字で階層を表す。

スキル・共通資格はほぼ等幅の2列に配置する。左列は太字の名称と任意の経験期間、右列は灰色の説明。横の点線で行を分け、外枠と縦罫線は付けない。長いセルは35mm以下の断片へ分割して改ページできる。色は断片ごとに適用し、後続の本文へ漏らさない。

会社の案件がある場合だけ「主な実績」を出す。案件は概要→担当フェーズ→業務内容→実績・取り組み→規模→言語→技術→URLの順。会社や案件全体を分割不能な箱にせず、本文は段落・行単位で改ページする。見出し前には後続数行分の空きを確保する。自己PRが空なら見出しも省略し、空の末尾ページを増やさない。

通常・空の架空fixtureは1ページ、長いスキル説明／案件本文／自己PR／区切りのないURLは複数ページになる。実PDFから全文・順序・A4寸法・各行のリンク先を検証し、欠字・はみ出し警告と孤立見出しを検査する。写真の配置は履歴書だけに適用する。全フィールド最大長の網羅はT20で行う。

## 単体コンパイルの確認

開発用exampleはJSONから**新しい**ディレクトリへbundleを展開する。既存ディレクトリへの上書きは行わない。

```sh
cargo run --manifest-path src-tauri/Cargo.toml --locked --example project_to_tex -- tests/fixtures/project-full.json resume /tmp/resume-bundle
cd /tmp/resume-bundle
latexmk -norc -lualatex -interaction=nonstopmode -halt-on-error -latexoption=-no-shell-escape main.tex
```

職務経歴書は`resume`を`career`へ変えて別の新規ディレクトリを指定する。Rust結合テストは正式全項目・書式・版拒否・写真資源・実FS保存を検証し、`pnpm test:tex`は空／全項目の両書類をアプリと同じ隔離コンパイルと展開後の単体コンパイルで確認する。実macOS E2Eは保存・再起動後の両書類を画面操作から生成し、実PDFの文字とPDF.js描画を確認する。
