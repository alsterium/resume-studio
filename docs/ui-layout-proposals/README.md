# UIレイアウト画像案（T36）

2026-10-07。PRD F01〜F13 / N05・N07を元に、組み込み画像生成ツールで作成した比較用モックアップ。UIコード・データモデル・TeXテンプレートの変更は含まない。画像内の細部と日本語は生成による表現であり、実装仕様としては以下の要件と保存したプロンプトを優先する。

## 共通要件

- macOSのローカル専用アプリ。1プロジェクトで履歴書と職務経歴書を切り替える。
- 固定項目は構造化フォーム、本文はWYSIWYG。履歴行の追加・削除・並べ替えを維持する。
- 保存は明示操作。新規・開く・保存・名前を付けて保存と未保存状態を表示する。
- PDFは読み取り専用で、PDF更新による手動生成。編集後は更新前のPDFであることを明示する。
- テンプレート選択、ページ移動、倍率変更、表示中／両方のPDF・TeX一式の出力を設ける。
- 主要操作を固定し、入力とPDFを別々にスクロールする。診断やログは二次操作へ配置する。
- 架空データのみ。クラウド同期・ログイン・AI文章生成・自動保存・PDF直接編集は追加しない。

## 目視確認と実装時の補正

3案とも書類切替、未保存表示、入力とPDFの分離、更新前バナーと手動更新が視認できることを確認した。Aは3ペイン、Bは横ステップと行編集、Cは本文編集と2ページの見開き確認を表現している。

- 画像内の「JIS準拠」「厚生労働省様式」等は生成された仮表記。PRDに従って規格準拠を表明せず、実際の版付きテンプレート名へ置き換える。
- Aの住所検索と必須表示、Cのリンク書式は既存機能の保証ではない。既存の検証条件・本文書式に合わせる。
