# 標準テンプレートの参考書式

## 1. 方針と観察範囲

利用者指定のローカルPDFを全7ページ、画像として確認した。1〜2ページが履歴書、3〜7ページが職務経歴書。志望動機は履歴書の欄に含まれ、独立した志望理由書ページは確認できない。

標準テンプレートはこの書式に近づける。書類の構成、罫線、見出し、余白、情報の階層を再現し、個人の氏名・写真・連絡先・経歴本文はfixtureやリポジトリに収録しない。元PDFと確認用画像もリポジトリに同梱しない。

以下の寸法は画像からの概算を基にした実装初期値であり、元PDFの厳密な座標・フォント測定値ではない。生成サンプルをレンダリングして調整する。原本は約595×842ptで、A4縦相当。

## 2. 共通の紙面

| 要素 | 観察した特徴 | 実装初期値 |
| --- | --- | --- |
| 用紙 | A4縦、白背景 | A4、210×297mm |
| 本文領域 | 左右・上下に余白、幅広い本文 | 左右18mm、上下18〜20mm |
| 書体 | 日本語ゴシック系、本文は黒〜濃灰 | TeX環境のHarano Aji Gothicを候補に固定 |
| 本文サイズ | 読みやすい密度、職務経歴書は行間に余裕 | 10.5〜11pt、行送り16〜18pt |
| 色 | 黒、濃灰、薄灰。装飾色なし | 白黒印刷で階層が判別できる濃度 |
| ページ番号 | 目視範囲では番号なし | 標準ではページ番号を表示しない |

## 3. 履歴書：罫線付き2ページ

### 1ページ目

上部左に字間を空けた「履 歴 書」、その右に書類日付と「現在」。右上に縦長の証明写真。写真はおおむね30×40mmを初期値とし、アスペクト比を維持して枠内に収める。

氏名ブロックには、ふりがな、名前、生年月日、満年齢、任意の性別表示を置く。名前は本文より大きくする。年齢は書類日付時点で計算し、生年月日とは別入力にしない。性別は未入力を許可し、文字列の表示とする。

次に、住所ふりがな、郵便番号・現住所を左の広い欄、電話・メールを右の狭い欄に配置する。その下に任意の別連絡先を同じ構造で置き、未入力時も空の欄を維持する。

下部は「年／月／学歴・職歴」の3列の表。列幅の初期値は12%／8%／80%。年と月は中央揃え、本文は左揃え。学歴・職歴の区分行は中央、終端の「以上」は右揃え。外枠はやや太い実線、行罫線は細い実線、年と月の間やふりがな区切りは点線。

### 2ページ目

上から順に次の領域を配置する。

1. 学歴・職歴の継続表。通常データで続きがなくても空行を表示する。
2. 「年／月／免許・資格」の3列の表。終端に「以上」、残りは空行。
3. 「志望動機・特技・アピールポイントなど」の罫線付き本文欄。
4. 「本人希望欄」の罫線付き本文欄。補足説明は小さめの文字。

通常の入力量は2ページで収める。表の初期配分は1ページ目16行程度、2ページ目の継続6行程度、資格6行程度を目安に試作する（見出し行を除く）。行数はテンプレート設定に置き、長い行は折り返して必要な高さを確保する。見た目の行数より全文表示を優先する。

学歴・職歴の余剰は継続表へ送り、さらに必要なら追加の継続ページを作る。資格・志望動機・本人希望も超過時は本文を欠落させず継続ページへ送り、プレビューで警告する。追加ページの順序は履歴書本体2ページの後、学歴・職歴→資格→志望動機→本人希望とする。

## 4. 職務経歴書：見出し＋表＋会社／案件

### 冒頭とセクション

左上に太字の「職務経歴書」と二重の横線。その下の右側に書類日付、氏名を縦に配置する。本文は次の順序とする。

1. 経歴要約
2. 活かせるスキル・経験
3. 職務経歴
4. 自己PR

セクション見出しは太字で本文より大きく、下に全幅の細い横線を置く。初期値はタイトル18pt、見出し14pt。見出し直後に十分な本文が置けない場合は見出しごと次ページへ送る。

### スキル・経験

2列の一覧。左に技術名・実務経験年数・資格名などの短いラベルを太字、右に説明を濃灰で表示する。列幅は概ね1:1、行間は薄い点線。外枠や縦罫線は表示しない。

スキルと資格を別の入力配列として保持しても、このセクションでは同じ2列書式で続けて表示できる。経験年数はラベルに埋め込まず任意の独立フィールドとし、本文ラベル生成時に組み合わせる。

### 会社と案件

会社単位で薄灰の全幅帯を置き、左に太字会社名、右に在籍期間。在籍中の表示を扱う。帯の下に事業内容・資本金・従業員数など任意の会社概要を置く。

各会社の「主な実績」の下に案件を順番に表示する。案件見出しは中抜き菱形の記号、太字案件名、やや小さく濃灰の期間。チェック記号や菱形はTeXで描画するか対応フォントで表現し、欠字を避ける。

案件の構成は次の通り。未入力の任意項目は見出しごと省略する。

- 【プロジェクト概要】：本文
- 【担当フェーズ】：設計・開発・テストなどの短い表示
- 【業務内容】：箇条書き
- 【実績・取り組み】：箇条書きまたは段落
- 【プロジェクト規模】：チーム規模など
- 【使用言語】：言語一覧
- 【使用技術】：フレームワーク・ツールなど
- URL：任意の参照先

案件詳細は複数ページをまたいでよい。会社全体や案件全体を改ページ禁止の箱に入れない。会社帯・案件見出し・小見出しの孤立は避ける。元PDFのページ境界は固定しない。URLは紙面幅で折り返し、任意のhttps/httpリンクとして出力可能にする。

自己PRは入力がある場合、最後に同じ見出しと下線を置き、複数の段落で表示する。空の場合は見出しごと省略する。

## 5. データ・エディタへの反映

| 対象 | 追加・具体化する入力 |
| --- | --- |
| 基本情報 | 住所ふりがな、任意の性別表示、別連絡先（郵便番号・住所・ふりがな・電話・メール） |
| 年齢 | 生年月日と書類日付から算出。閏年と誕生日境界をUnitテスト |
| スキル | 技術名、任意の経験期間表示、説明 |
| 職務経歴 | 会社単位の在籍期間・役職・会社概要と、複数の案件 |
| 案件 | 名前、期間、概要、フェーズ、業務内容、実績、規模、言語、技術、URL |
| 編集 | 会社・案件・スキルの追加／削除／並べ替え。長文項目は既存の限定WYSIWYGを利用 |

URLは専用入力欄で扱い、本文の任意リンクmark対応は後続のままとする。T44では履歴書と職務経歴書の資格を別配列として保持する。職務経歴書の資格名を左列、取得年月を右列に「N年M月 取得」で表示し、未入力は空欄にする。

## 6. 受け入れと検証

- 架空データで通常の2ページ履歴書と複数ページ職務経歴書を生成し、上記の領域・順序・罫線・灰色帯・太字・下線を確認する。
- 原本の本文や写真を使う画像snapshotは作らない。架空サンプルから生成したPDF／画像を視覚回帰の基準にする。
- 通常データ、長い住所、長い学校名、多数の学歴・資格、長文案件、長いURL、写真なしを検証する。
- PDFの文字抽出で末尾の目印まで存在すること、欠字・大幅なはみ出しがないことを確認する。
- 設計上の寸法を守るだけでなく、実際にPDFを画像化して紙面の近さを確認する。元PDFとのピクセル完全一致は要求しない。

TeXテンプレート実装と生成サンプルの確認はM4で行う。履歴書の帳票・続紙はT18で実装し、具体的な寸法と検証範囲を[TeX出力契約](GENERATED_TEX.md#履歴書の帳票と続紙)に記録する。職務経歴書の見出し・灰色帯・スキル表と長文改ページはT19で実装し、[TeX出力契約](GENERATED_TEX.md#職務経歴書の流し込み)に記録する。最大長・本文64KiB・写真形式の検証範囲と再現方法は[TeX出力契約のT20マトリクス](GENERATED_TEX.md#t20の検証マトリクスと目視qa)に記録する。

## 7. JIS形式を参考にした履歴書1.1.0（T34）

2026-10-07、ユーザー依頼でWeb上のTeX履歴書を優先調査した。参考は[多摩通信社の履歴書スタイル](https://www.tamacom.com/rireki-j.html)、[shigio/rireki-style](https://github.com/shigio/rireki-style)、[出力例](https://www.tamacom.com/rireki/rireki.pdf)。GitHub版はupLaTeX／LuaLaTeXに対応するB5×2枚。年月列・中央の学歴／職歴区分・右上の30×40mm写真・点線のふりがな区切りを参考にした。外部コードは取り込まず、既存のマクロと全文保持処理を使ってA4へ組版した。JIS認証や旧JISの全項目再現を示すものではなく、家族／通勤項目は追加しない。

版1.1.0は左右18mm、上下16mm。タイトル19pt、氏名18pt、本文10.5pt／17pt。外枠0.45pt、内罫線0.25〜0.3pt。基本情報を最小40mmで写真枠と揃え、氏名と生年月日の間で余白を配分する。年18mm／月10mmで内容列を広げる。1ページ目はページビルダーへ連絡先を確定させた後、残りの高さから表見出しと段落間隔18mmを引いて経歴欄を伸縮する。2ページ目の本文領域は経歴37.5mm／資格45mm／志望動機90mm／本人希望60mm。長文は従来同様に続紙へ送る。

旧版1.0.0を同梱のまま保持し、新規プロジェクトの既定のみ1.1.0へ変更する。既存プロジェクトは「テンプレート一覧を確認」→「履歴書テンプレート」で「標準履歴書（JIS形式）1.1.0」を選択してPDFを更新する。新版はTeX一式を書き出して単独コンパイル可能。

## 8. 参照原本への再調整（T35）

ユーザー指定の同じ7ページPDFを再確認し、画像とPDFKitのラベル座標・フォントサイズを測定した。原本は594.96×841.92pt。履歴書の本文は約11.26pt、ラベル9.00pt、氏名15.76pt、タイトル18.01pt。職務経歴書は本文10.51pt、セクション13.51pt、会社名12.01pt、タイトル18.01pt。PDFKitの代替フォント名から実フォントの種類は断定せず、見た目の太さと文字寸法を調整する。原本の本人データ・写真・テキスト・画像はGitへ収録しない。

履歴書1.2.0は左右／上下18mm、約174mm幅。氏名ブロックは120mm幅、ふりがな6.5mm／名前18mm／生年月日14mmを基本に自然高さを測定。氏名はラベルの右、日付は同ブロックの右端に置く。写真はx=150mm付近、30×40mmで枠線なし。現住所24mm／別連絡先20mmを最小高とし、長い値は拡張、極端に長い値は続紙へ全文を送る。原本と同じ年月列12%／8%、表見出し8mm、行高9.5mm。1ページ目16行（152mm）を基本に長い連絡先では縮小、学歴と職歴の間に空行。2ページ目の学歴・職歴6行／資格6行（各57mm）、自由欄は各49mmの本文領域＋ラベル。自由欄内の見出し直下の横線を除き、本人希望の説明を同じ行に置く。

両新版は日本語フォントのスケールを1へ明示し、本文にHarano Aji Gothic Regular、太字にBoldを使う。診断にRegularの存在確認を追加。職務経歴書1.1.0は本文10.5pt／17pt、見出し13.5pt、会社名12pt、案件期間9pt。案件名と期間を同じ行、本文ラベルを通常ウェイトで表示する。会社／スキル／本文の流し込みと長いURLを保持し、見出しと次の内容が孤立しない高さを確保する。

新規の既定は履歴書1.2.0／職務経歴書1.1.0。旧版はすべて保持し、既存JSONは明示的にテンプレートを切り替える。レイアウトを測定して近づけるが、原本と異なるフォント・入力・改行指定では字形や折返し、職務経歴書のページ境界は変わる。原本は志望動機を履歴書の欄に含み、独立した志望理由書ページはない。

## 9. 固定欄の表示不具合修正（T47）

既定の履歴書1.2.0に対する修正として、電話は現住所ラベルと同じ9ptで、隣の住所ふりがな欄と同じ高さの領域内に垂直中央配置する（両欄の下罫線を揃える）。Email・志望動機・本人希望欄のタイトル上に1mmの余白を置く。年齢と任意性別の間の縦罫線を除去し、性別表示は保持する。学歴・職歴・免許/資格は罫線込み9.5mmの固定行とし、「以上」も同高にする。内容列の左右2mmの余白を除いた幅を通常11.25ptで測定し、超過する行だけ縦横比を保持して文字を縮小する。通常行の文字サイズ・表の高さ/幅・件数超過時の続紙は維持する。極端な長文は一行へ縮小するため文字が小さくなるが、切捨てはしない。名前欄を含む基本情報ブロックの右罫線の中心は、現住所の左右を分ける縦罫線の中心へ揃える。旧1.0.0/1.1.0は変更しない。

## 10. 基本情報と連絡先の連結（T48）

名前・生年月日のブロックと現住所・別連絡先を余白なしで接続し、一つの段付き外枠で囲む。写真は上段右の枠外に配置する。外枠および生年月日下の境界は1.2pt、現住所と別連絡先の境界は0.4ptとする。年月表・資格・志望動機・本人希望欄・続紙の外枠も1.2ptに統一し、内部の細線と点線を維持する。T47の電話サイズ/中央/隣接欄の高さ、タイトル内余白、9.5mm行高、文字縮小を維持する。

## 11. 名前ラベルとふりがな（T49）

名前欄だけはラベルと氏名の組版ボックスの縦中央を揃え、9ptラベル/15.75pt氏名のサイズ差でも中央に置く。名前・現住所・別連絡先のふりがなは通常9ptで測定し、値の欄幅（左右2mm余白を除く）を超える場合だけ縦横比を保って縮小する。ふりがなは改行で欄を拡張せず一行へ収め、文字を省略しない。

## 12. 年齢と性別の独立領域（T50）

生年月日と年齢は同じ99mm領域へ置き、性別は残り幅に置く。年齢だけを分ける線は引かず、性別の手前だけに通常0.4ptの縦罫線を行の全高に引く。各領域は垂直中央、行高は従来14mm以上で、長い任意性別は従来の続紙退避を維持する。年齢は（満XX歳）とし、生年月日が未入力で年齢がない場合は括弧も出さない。T47の縦罫線除去はこの追加指定で置き換える。

## 13. 年齢の右揃え（T51）

生年月日と括弧年齢の共有99mm領域を右揃えとし、生年月日の直後に（満XX歳）を配置する。左右2mm余白、性別手前の縦線、垂直中央配置、行高を維持する。
右揃え設定後にrightskipを2mmへ明示し、年齢の右端と性別罫線の間に2mm余白を確保する。
