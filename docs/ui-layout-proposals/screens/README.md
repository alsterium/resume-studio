# C案の画面別レイアウトと実装（T38）

採用したC案を、左の編集パネルと右の大きなPDF表示で統一した。上部にプロジェクト操作、左に書類タブと編集項目の折りたたみ、右にテンプレート・PDF更新・ページ操作を置く。画像は生成した設計資料であり、実アプリのスクリーンショットではない。[生成プロンプト](prompts.json)に全12画面の要件を保存した。

| 画面 | 生成画像 | 実装 |
| --- | --- | --- |
| 基本情報・写真 | [基本情報](profile.png) | 共通プロフィール、写真の取込・削除 |
| 学歴・職歴 | [学歴・職歴](history.png) | 年月・内容、追加・削除・並び替え |
| 免許・資格 | [免許・資格](qualifications.png) | 両書類で共有する資格の編集 |
| 志望動機 | [志望動機](motivation.png) | 本文と書式ツールバー |
| 本人希望 | [本人希望](preferences.png) | 本文と書式ツールバー |
| 職務要約 | [職務要約](summary.png) | 職務経歴書の要約編集 |
| 職務経歴・案件 | [職務経歴](career.png) | 会社・案件・業務内容の編集 |
| スキル | [スキル](skills.png) | 名称・期間・説明、追加・並び替え |
| 自己PR | [自己PR](self-promotion.png) | 本文と書式ツールバー |
| 書き出し | [書き出し](export.png) | PDF/TeX一式、表示中/両書類、結果表示 |
| 設定・TeX診断 | [設定](settings.png) | TeX環境の確認とアプリ情報 |
| 未保存の確認 | [未保存の確認](unsaved.png) | キャンセル・破棄・保存して続行 |

実装は公式shadcn/uiのButton、Tabs、Accordion、Resizable、Dialog、DropdownMenu、Input、Badgeを使用する。PDFは実際の生成結果をPDF.jsで描画し、見開き／1ページ、幅合わせ／倍率、ページ送りに対応する。境界はドラッグして調整でき、狭いウィンドウでは上下配置へ切り替える。項目を閉じても本文エディタは保持され、書式とUndo履歴が残る。

画像に含まれる架空の紙面・入力例はアプリへ埋め込まない。年/月の入力、連絡先、会社・案件の項目は既存のProject契約に合わせる。画像生成で描かれた下線・リンク等は追加せず、既存の太字・斜体・箇条書き・番号付きリストを維持する。生成結果がない時は案内を表示する。書き出しとTeX診断はモーダルに移し、書き出し中も閉じて編集を続けられる。
