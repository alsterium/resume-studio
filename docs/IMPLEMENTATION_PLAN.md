# 実装ロードマップ

## 進め方

進捗の正本は [JSONLタスク台帳](../tasks/tasks.jsonl)。着手・検証・完了の運用は [開発規約](DEVELOPMENT.md) に従い、HTMLダッシュボードから確認する。

M0 → M1で「入力→TeX→実PDF表示」を動かし、M2以降で書類の内容と保存を増やす。最初に大きなエディタを作らず、macOSのWebViewと外部TeXの連携を検証する。

各タスクは1つのPRとしてレビューできる規模に分割する。工数はM1の結果を見て見積もり、現時点で納期を固定しない。
