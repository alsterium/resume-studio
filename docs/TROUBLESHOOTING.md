# 生成・保存の失敗から復旧する

失敗した操作では編集内容を破棄しない。PDF更新や書き出しが失敗しても、プレビューの最後の成功PDFを表示する。追加編集がある場合は「PDFは更新前の内容です」と表示するので、復旧後に更新する。書き出しは現在の入力から生成し、プレビューとは別に書類ごとの結果を表示する。

## TeX環境の確認

「TeX環境を確認」を押す。実行ファイルの版・不足資源・日本語PDFの生成結果を確認できる。TeX環境がなくてもJSONの編集・保存とTeX一式の書き出しを利用できる。

| 表示・資源 | 対処 |
| --- | --- |
| latexmk / lualatex / kpsewhich が未検出 | システムのTeX環境へ追加する。macOSではPATHのほか`/Library/TeX/texbin`も探索する |
| ltjsarticle.cls / luatexja-preset.sty | luatexjaパッケージを確認する |
| regexpatch.sty | regexpatchパッケージを確認する |
| graphicx.sty / color.sty | graphicsパッケージを確認する |
| geometry.sty / hyperref.sty | 表示されたパッケージを確認する |
| HaranoAjiMincho-Regular / Bold、HaranoAjiGothic-Medium / Bold の.otf | haranoajiのフォントを確認する |

追加方法は使用中のTeXディストリビューションのパッケージ管理方法に従う。アプリはパッケージの自動インストールや環境の書き換えを行わない。追加したら再診断する。

## エラーコードとログ

| コード | 次の操作 |
| --- | --- |
| TEX_NOT_FOUND / TEX_DEPENDENCY_MISSING | 環境診断で不足を確認し、補ってから再実行する |
| COMPILE_FAILED | まず環境を確認する。環境が揃っていれば「生成ログを表示」で失敗箇所を確認する |
| TIMEOUT | 各PDFの生成は60秒まで。入力の量とTeX環境を確認して再実行する |
| IO_ERROR | ディスクの空き容量と書込権限を確認する。保存操作は別の保存先を選べる |
| OUTPUT_TOO_LARGE | PDFは20MiBまで。入力や写真を見直して再生成する |
| TEMPLATE_NOT_FOUND | 対応しているテンプレートを明示的に選択する。入力JSONを読み込むだけで選択を勝手に置き換えない |

生成ログは折りたたんで表示し、HTMLとして実行しない。標準出力・標準エラーは各先頭64KiBまで保持する。ログの閲覧に外部サービスは使わず、内容を自動送信しない。

## 保存が失敗した場合

JSONとPDFは一時ファイルを書いてから置換する。置換失敗時は元のファイルを維持し、JSONの未保存状態を保持する。「名前を付けて保存」または書き出しの保存先選択で別の場所を選べる。既存の読取専用ファイルやsymlinkは書き出しの置換対象にできない。

TeXは一式を準備してからフォルダを置換する。未知のファイルや書込不可の資源がある既存TeXフォルダは置換しない。外部でコンパイルした補助ファイルがある場合も、別の保存先を選ぶ。置換・復元の両方が失敗した場合は、エラーに表示した退避先へ元の資源を保持する。表示された場所から元の資源を確認し、別の保存先へ書き出す。

両書類を出力した場合、片方の失敗で他方の成功ファイルは取り消さない。結果一覧で保存・スキップ・失敗を確認する。上書き確認でスキップした原本は変更しない。
