# ADR 0004: macOSデスクトップE2E

状態: 採用（2026-10-06、ホストCIの実行確認中）

[Tauri公式資料](https://v2.tauri.app/develop/tests/webdriver/)のembedded方式を採用する。WebdriverIO 9.30.1のstandalone clientがtauri-plugin-wdio-webdriver 1.4.0のW3C serverへ接続する。単一の既知バイナリをテストするため、CLI/serviceの自動検出や追加のexecute/mockプラグインは不要。Node.jsのtools/desktop-e2e.mjsが空きポートの選択、子プロセスの起動、期限付きready待機、セッション削除、子プロセスの終了を担う。

プラグインはoptional dependencyとdesktop-e2e featureで有効にする。通常ビルドのfeature・capability・フロントへテスト用権限やJSを追加しない。CIで既定featureのcargo treeにテストサーバーが含まれないことを検証する。テスト中はローカルのWebDriver serverがアプリを操作できるため、専用プロセスを終了時に停止する。

テスト用.app bundle内の実行ファイルをPATH=/usr/bin:/binで起動し、GUIに近い環境のTeX検出と同梱資源も検証する。要素入力で日本語とTeX特殊文字を本文へ入れ、PDF更新の実IPC・実TeX・PDF.jsの描画ピクセルを検証する。新しい専用プロセスで初回生成結果ID「1」を実Rustコマンドから再取得し、Node.js側のPDF.jsで氏名・本文の文字保持も確認する。embedded driverのkeyboard actionsはcontenteditableの文字挿入を実装していないため、要素のaddValueを使う。selectのoption clickではchangeイベントが発火しなかったため、倍率変更のみbrowser.executeでnative value setterとDOM changeイベントを操作する。PDF生成と描画は代替しない。これらはOSのIMEやnative selectの実操作テストではなく、実IMEはT08のユーザー確認を別証跡として保持する。

macOS CIはBasicTeX 2026.0301のpkgをCTANのIllinoisミラーから取得し、Homebrew公式cask掲載のSHA-256を照合して導入する。自動選択ミラーはCIで証明書期限切れの取得先に転送されたため、pkgとtlmgrの取得先を固定した。証明書検証を無効にしない。latexmk・luatexja・haranoaji・regexpatchと依存をtlmgrで追加する。追加パッケージの完全なsnapshot固定はT25で拡充し、現時点では基礎配布の固定と実行時の版記録を行う。TeX未導入時に成功扱いでskipしない。

PDF.jsの通常版はMap.getOrInsertComputedがない実WebViewでページ描画に失敗することをローカルで再現した。legacy版の本体とworkerへ切り替え、同APIを無効にした実E2Eが成功した。専用プロセス内でのみAPIを無効にし、互換性の退行を検出する。PDF描画例外はconsoleへ記録し、E2Eが取得する。W3C driverはexecute返却値のerrorフィールドをエラー応答として解釈するため、状態報告にはfailureを使う。
